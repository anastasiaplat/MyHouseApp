# Mobile app for creating interactive map of dynamic buttons
The app is my diploma project for bachelor and master degrees. Did nothing essential actually, but i did it almost all by myself with just a liitle consultations of Yandex Alice.

In this app you can add new buttons with naming it, giving certain sizes and even settle down it on improvising map. You can also edit it, of course, or just delete if you dont like it.
Buttons will be direct to another new page with certain list of real devices that you kinda connected to the app (i didnt considered it, just module of visual interactive map).

Actually it just a constructor of dynamic buttons, not big deal but it took a lot to think and organize to be honest.
